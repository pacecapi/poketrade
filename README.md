# PokeTrade

A demo marketplace for buying and selling Pokémon cards, built with React + Vite.

## Running locally

```bash
npm install
npm run dev
```

## Building for production / deploying (e.g. Vercel)

```bash
npm install
npm run build
```

This is a front-end-only prototype: listings, purchases, and the wishlist live in memory in the browser and reset on reload. There is no backend or real payment processing.
